## Presentación

Food Store es un sistema para realizar y gestionar pedidos de comida.

El proyecto tiene dos partes que funcionan de manera independiente:

- Una aplicación web donde el cliente puede consultar productos, armar su carrito y realizar pedidos. El administrador tiene un panel para gestionar categorías, productos y pedidos.
- Una aplicación de consola que permite gestionar categorías, productos, usuarios y pedidos, además de consultar reportes.

## Organización del proyecto

| `frontend` | Aplicación web desarrollada con HTML, CSS, TypeScript y Vite. Utiliza archivos JSON y almacenamiento local del navegador. | [README del frontend](frontend/README.md) |
| `backend` | Aplicación de consola desarrollada con Java 17, JPA, Hibernate y H2. Guarda la información en una base de datos. | [README del backend](backend/README.md) |

Cada carpeta tiene su propio README con los requisitos y los pasos para ejecutar la aplicación.
